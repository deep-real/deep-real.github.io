# ProstateVLM website — hosting handoff

Packaged September 25, 2026 from the latest approved local page.

## Publish under the group website

1. Extract this ZIP. It contains a `prostatevlm` folder.
2. Upload that folder to the group website's public directory, or copy its contents into your chosen project directory.
3. Keep `index.html`, `styles.css`, `app.js`, and the `assets` folder together with their existing names and relative locations.
4. Visit the project directory URL, for example `https://your-group-domain.org/prostatevlm/`. If the server does not automatically serve index files, open `index.html` at that URL.

This is a static website. No build step, Node.js, installation, database, API keys, or special hosting platform is required. All displayed images and icons are included or embedded. Links to papers, repositories, and researcher profiles lead to their existing external websites.

## Files

- `index.html` — page content
- `styles.css` — layout and styling
- `app.js` — result tabs and citation controls
- `assets/` — only the images and logos used by the page

You can open `index.html` locally after extraction for a quick review. After uploading, check the images, result tabs, and citation controls at the final URL. HTTPS is recommended for clipboard support.

Edit `index.html` to change text or links. Preserve the relative asset paths and the existing icon attribution comments. The README is for the hosting maintainer and does not need to be uploaded.
